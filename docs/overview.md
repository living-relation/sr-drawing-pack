# Overview

SR Drawing PDF is a Spark Robotic script for Autodesk Fusion. It makes a 4-view drawing PDF of the active design.

It is part of the Spark Robotic (SR-) tool set for Fusion.

## What this repository is today

This repository currently holds documentation, a license, and a Python `.gitignore`. The script code has not been added yet. Feature-specific behavior in these docs is marked as to be completed when the code lands.

## Features

- Create a 4-view drawing of the active Fusion design.
- Save that drawing as a PDF.

The four views, sheet layout, title-block content, and PDF options are to be completed when the code lands.

## Requirements

- Autodesk Fusion

No other requirements are documented yet. Runtime dependencies, if any, are to be completed when the code lands.

## Status

The script will be added in a follow-up pull request. Until then, treat this repository as the public home and documentation for **SR Drawing PDF**.
