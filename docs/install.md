# Install

This page describes a generic install through Fusion's Scripts and Add-Ins dialog. The exact folder to add, and any extra install steps, are to be completed when the code lands.

## Requirements

- Autodesk Fusion
- This repository, cloned or downloaded to a folder you can keep on disk

## Add the script in Fusion

1. Open Autodesk Fusion.
2. Open the **Scripts and Add-Ins** dialog. In current Fusion builds this is usually under **Utilities > Scripts and Add-Ins**. The menu label can vary by version.
3. Open the **Scripts** tab.
4. Use the control that adds a script from a folder (the green plus in current Fusion builds).
5. Select this repository folder, or the script folder named in the code when it lands.
6. Select the script in the list and run it. How it appears in the list, and any run options, are to be completed when the code lands.

If Fusion does not list the script after you add the folder, confirm you pointed at the folder the code expects. That path is to be completed when the code lands.

## Uninstall

Remove or stop the script from the same Scripts and Add-Ins dialog, then remove the folder from the list if Fusion provides that option. Details are to be completed when the code lands.
