**Status: planning. Nothing here is usable yet.**

Goal: generate engineering drawings from Autodesk Fusion designs in the handbuilt-cad sheet style
(title block, revision table, BOM with thumbnails), open every generated drawing for review and
editing, and export to PDF and DXF.
