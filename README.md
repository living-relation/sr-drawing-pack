# SR Drawing PDF

A Spark Robotic Fusion script that makes a 4-view drawing PDF of the active design.

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

## Features

- Create a 4-view drawing of the active Fusion design.
- Save that drawing as a PDF.

The four views, sheet layout, title-block content, and PDF options are to be completed when the code lands.

## Requirements

- Autodesk Fusion

Other dependencies, if any, are to be completed when the code lands.

## Install

Add this repository from Fusion's **Scripts and Add-Ins** dialog. Use the **Scripts** tab and add the script from a folder. See [docs/install.md](docs/install.md) for the full steps.

## Usage

Once the script is added in Fusion, run it from the Scripts and Add-Ins dialog to make a 4-view drawing PDF of the active design. Command names, options, and outputs are to be completed when the code lands. See [docs/usage.md](docs/usage.md).
